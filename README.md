## About This Portfolio

This is my personal portfolio website showcasing my skills, projects, and professional experience. Built with modern web technologies, it features a clean, responsive design with dark mode support.

### Features

- **Responsive Design** - Optimized for all devices (mobile, tablet, desktop)
- **Dark Mode** - Seamless theme switching with persistent preferences
- **Interactive UI** - Smooth animations and transitions
- **Fast Performance** - Built with Astro for optimal loading speed
- **SEO Optimized** - Proper meta tags and structured data
- **Accessible** - WCAG compliant design

### Portfolio Sections

- **About** - Introduction and background
- **Skills** - Technical skills organized by categories
- **Experience** - Professional work experience and internships
- **Projects** - Showcase of personal and professional projects

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- pnpm (recommended) or npm

### Installation

1. Clone the repository
```bash
git clone https://github.com/Udaysapate212/portfolio.git
cd portfolio
```

2. Install dependencies
```bash
pnpm install
```

3. Start the development server
```bash
pnpm dev
```

4. Open your browser and visit `http://localhost:4321`

### Build for Production

```bash
pnpm build
```

### Preview Production Build

```bash
pnpm preview
```
